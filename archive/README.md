# Archive

The old dotfig, kept for reference: the Makefile-driven setup, its stow-based
dotfiles (oh-my-zsh, the old tmux, vim, and git config), the CentOS and Ubuntu
package lists, pyenv (replaced by uv), PyCharm, and the macOS scripts that the
Brewfile and `install.sh` replaced. Nothing here is installed any more; the
oh-my-zsh and tmux plugin submodules are gone too.
